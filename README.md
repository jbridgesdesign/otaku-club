## 📖 About

Otaku Club is a fictional anime and manga meetup group homepage, built to practice **HTML & CSS**, **responsive design**, and **CSS layout techniques**, while also serving as a portfolio piece. The page features a bold hero banner, a photo gallery, a testimonial section, and a meetup call-to-action — all styled with a vibrant, anime-inspired color palette.

---

## ✨ Features

- **Hero Banner** — Full-width anime wallpaper header with a bold club title
- **Summary Section** — Club intro with a link to the fictional sponsor, Otakus R Us
- **Photo Gallery** — A three-image flexbox layout showcasing the club and its events
- **Testimonial Section** — A member quote section with bold, styled typography
- **Meetup CTA** — A dedicated section promoting the weekly Sunday meetup
- **Responsive Layout** — Media queries for three breakpoints (1048px, 640px, 320px)
- **Custom Typography** — Google Fonts integration (*Montserrat*)
- **Consistent Branding** — Cohesive color palette used across header, sections, and footer

---

## 🛠️ Built With

- HTML5 (semantic elements: `header`, `main`, `footer`, `nav`, `section`, `figure`)
- CSS3 (custom stylesheet with flexbox layout and responsive media queries)
- Google Fonts
- AI-generated images via **Google NanoBanana2**
- Background wallpaper via [Wallpaper Cave](https://wallpapercave.com/w/wp4474569)
